# موقع شركة آرك الماسية العقارية

موقع ثابت (HTML/CSS/JS) عربي RTL متجاوب، بدون أي أدوات بناء.

- التشغيل: افتح `index.html` أو `python3 -m http.server`.
- عدّل رقم واتساب في `assets/app.js` (`WA`) وفي `index.html` (روابط `tel:` و`wa.me`) وبيانات التواصل.
- العقارات في مصفوفة `PROPS` داخل `assets/app.js`.
- الصور حاليًا تدرجات لونية؛ استبدلها بصور العقارات الحقيقية والشعار الرسمي (`assets/logo.svg`).
