# موقع شركة آرك الماسية العقارية

موقع ثابت (HTML/CSS/JS) عربي RTL متجاوب بدون أدوات بناء، مع مشهد ثلاثي الأبعاد (Three.js) وحركات تمرير (GSAP + Lenis) تُحمَّل من CDN. البنية مستوحاة من مواقع المطوّرين العقاريين في جدة: بحث بالحي/الحالة/الغرف/الميزانية، مشاريع، أحياء، رحلة العميل، ضمانات، شركاء، أخبار.

- التشغيل: افتح `index.html` أو `python3 -m http.server`.
- **كل البيانات الحالية تجريبية** وتُعدَّل في أعلى `assets/app.js`:
  - `WA`: رقم واتساب (وعدّل روابط `tel:` في `index.html`).
  - `PROJECTS`: المشاريع والوحدات المتاحة والأسعار (الفلاتر والعدّادات تُحسب منها تلقائيًا).
  - `NEWS` و`PARTNERS`: الأخبار والشركاء.
- `assets/scene.js`: المشهد ثلاثي الأبعاد (الماسة والمدينة ومسار الكاميرا حسب التمرير).
- الصور حاليًا تدرجات لونية؛ استبدلها بصور المشاريع الحقيقية والشعار الرسمي (`assets/logo.svg`).
