# موقع سكون المباني للتطوير العقاري

موقع ثابت (HTML/CSS/JS) عربي RTL مع نسخة إنجليزية، GSAP + ScrollTrigger + Lenis من CDN.
المشهد الافتتاحي: مخطط أزرق (خطوط مستخرجة من صورة المبنى) يُرسم، ثم يتحول للمبنى الحقيقي، ثم للّيل.

- التشغيل محليًا: من مجلد `work` شغّل `python -m http.server` وافتح `/sukoon/`.
- النصوص العربية داخل `index.html`، والإنجليزية وكل البيانات في `assets/data.js`.

## المصادر
- الملف التعريفي 2026-2027: النصوص، الأرقام، الضمانات، العوائد، كلمات الإدارة، الصور، الشعار (SVG مستخرج من الملف)، لوحة الشركاء.
- Linktree الرسمي (linktr.ee/sukoonc.2030): أسماء المشاريع الحالية وأحياؤها، أرقام المبيعات، روابط صور المشاريع، إنستقرام وX، موقع الإدارة.
